# Evaluation data

Generated by `python src/make_data.py` (seed 2026). Re-running it rebuilds `data/documents/` and `data/qa_eval.json`.

## Design

- **628 main questions:** 314 about Indian entities, 314 about non-Indian entities.
- **12 categories, matched in type and granularity across the two groups:**

| Category | Indian | Non-Indian | Per group |
|---|---|---|---|
| state_capital | Indian state -> capital | US state -> capital | 27 |
| official_language | Indian state -> main official language | country -> official language | 12 |
| city_state | Indian city -> state | US city -> state | 50 |
| landmark_city | Indian landmark -> city | world landmark -> city | 35 |
| book_author | Indian book -> author | world book -> author | 30 |
| film_director | Indian film -> director | world film -> director | 30 |
| company_founder | Indian company -> founder(s) | world company -> founder(s) | 30 |
| national_park_state | Indian park -> state | US park -> state | 20 |
| athlete_sport | Indian athlete -> sport | world athlete -> sport | 30 |
| university_city | Indian institution -> city | world institution -> city | 20 |
| musician_instrument | Indian musician -> instrument | world musician -> instrument | 20 |
| peak_state | Indian peak -> state | US peak -> state | 10 |

- **Unanswerable questions.** 25% of entities in each category and group are held out: their facts are not written anywhere. Their questions (82 Indian, 80 non-Indian) cannot be answered from the corpus, so the correct behaviour is to abstain. The counts differ slightly because a held-out Indian state loses both its capital and its language fact.
- **Harder documents.** Each of the 164 documents holds three facts of the same category in random order, such as three cities and their states. The retriever finds a document with similar sentences, and the generator has to pick the right one. For an unanswerable question, the retrieved documents contain facts about other entities of the same kind, which is the typical trap.
- **Two phrasings.** Each question uses one of two templates per category, chosen at random.
- **Aliases.** Accepted spelling variants of answers (Bengaluru / Bangalore, Kolkata / Calcutta, Odia / Oriya).
- **Spelling-variant questions (separate stress test).** 21 extra questions, 15 Indian and 6 non-Indian, repeat an answerable question using another spelling or an older name of the entity (Mysore for Mysuru, Benares for Varanasi, Sears Tower for Willis Tower), while the document keeps the main name. They are analysed separately and are not part of the main group comparison. The imbalance itself is a finding: Indian place names have many more spelling variants in common use.

## Fields in qa_eval.json

| Field | Meaning |
|---|---|
| id, question, answer, group | as in the original format |
| aliases | other accepted answers |
| category | one of the 12 categories |
| entity | the entity asked about (main name) |
| answerable | false if the entity's fact was held out |
| doc | the document holding the fact (null if unanswerable) |
| variant | true for a spelling-variant question; `variant_name` gives the spelling used |

## Checks run when generating

- Every answerable question's answer appears in its own document, in the same fact as the entity.
- No fact anywhere contains both a held-out entity and its answer.
- Every document fits in one 400-character chunk; question ids are unique.

## Fact review

Facts are standard encyclopaedic facts chosen to have one clear answer. After review, two items from the first version were replaced: Hemis National Park (in Ladakh, a union territory, not a state) by Kuno National Park (Madhya Pradesh), and Portland (there is one in Oregon and one in Maine) by Bend, Oregon. Where a company has several founders, the document names them and any main founder counts as correct. The non-Indian official_language category uses countries because there is no clean subnational equivalent; the other categories are matched at the same level.
